# Roblox Baza | SA — Telegram-бот

Готовый бот по приложенному техническому заданию.

## Возможности

- приветствие с custom emoji и постоянным меню;
- сценарий «Задать вопрос»;
- команды `/start`, `/check`, `/me`, `/id`;
- карточки «Проверенный гарант», «Просто гарант», «Обычный пользователь»;
- автоматическая подстановка Telegram-профиля и ID;
- красная кнопка жалобы и кнопка профиля;
- закрытая панель управления ролями, пруфами, ссылками и Roblox-никами;
- добавление и удаление администраторов владельцем;
- SQLite-база, которая создаётся автоматически рядом с `main.py`.

## Запуск

Нужен Python 3.11 или новее.

### Windows

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

Запускайте бота напрямую через `python main.py`. При первом запуске программа
один раз попросит токен Telegram-бота и сохранит его в локальный
`bot_token.txt`. Этот файл исключён из Git и не попадёт в публичный репозиторий.
На хостинге токен можно задать переменной окружения `BOT_TOKEN`.

Первый пользователь, который откроет закрытую панель, становится владельцем.
Команда панели намеренно не добавлена в список команд Telegram и нигде в
интерфейсе не показывается.

## Важное про custom emoji

Для отображения переданных custom emoji владелец бота должен иметь Telegram
Premium либо бот должен соответствовать условиям Telegram для отправки custom
emoji. Если Telegram не разрешит конкретный custom emoji, останется обычный
emoji-символ.

## Проверка другого пользователя

- `/check @username`
- `/check 123456789`
- ответить `/check` на сообщение пользователя в группе

Telegram не позволяет боту получить ID произвольного `@username`, если этот
пользователь ещё нигде не взаимодействовал с ботом. В таком случае используйте
числовой Telegram ID или попросите пользователя написать боту.
